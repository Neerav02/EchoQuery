# Phase 11: Milestone 4 — Test Reliability Remediation

## Objective
Fix the confirmed runtime `NameError` caused by the stray `s` in `app/tests/test_celery_and_frontend.py:23`, align existing tests with the remediated security and migration behavior, and validate the complete EchoQuery v2.0 test suite end-to-end.

## Execution Context
- **Planning only**: Do not edit test files or execute `pytest` during planning.
- **Root cause verified in codebase**:
  - `app/tests/test_celery_and_frontend.py:23` contains:
    ```python
    res = subprocess.run(s
        [sys.executable, "-c", code],
        cwd=REPO_ROOT,
        capture_output=True,
        text=True,
        timeout=15,
    )
    ```
    In Python, `s\n[sys.executable, "-c", code]` is parsed as subscripting `s[...]`, so the module compiles without a `SyntaxError` and fails at runtime with `NameError: name 's' is not defined` when `test_celery_task_registration_windows_host_layout` runs.
- **Sequencing**:
  - Fix `11-01` (stray `s`) can be applied immediately, while final end-to-end regression verification (`11-02`) runs after Phases `08`, `09`, and `10` fixes are in place so every newly added/updated regression test executes together.
